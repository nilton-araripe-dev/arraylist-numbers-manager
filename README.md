# Gerenciador de Números Dinâmico (Console)

Este é um projeto desenvolvido em Java que simula um sistema de gerenciamento de números via console. O objetivo principal é consolidar conhecimentos em estruturas de repetição, condicionais, manipulação de listas dinâmicas (`ArrayList`) e modularização com métodos estáticos.

## 🚀 Funcionalidades

O programa oferece um menu interativo com as seguintes opções:
1. **Adicionar números:** Permite inserir múltiplos números reais (`Double`) na lista de uma só vez.cd nome-do-seu-repositorio
2. **Mostrar números:** Exibe todos os valores atualmente armazenados.
3. **Mostrar média:** Calcula e exibe a média aritmética de todos os números.
4. **Mostrar maior número:** Identifica o maior valor presente na lista.
5. **Mostrar menor número:** Identifica o menor valor presente na lista.
6. **Buscar número:** Verifica se um número específico está na lista.
7. **Remover por índice:** Exclui um elemento com base na sua posição (índice) na lista.
8. **Mostrar quantidade de pares:** Conta quantos números inseridos são inteiros e pares.
9. **Limpar lista:** Esvazia toda a lista após uma confirmação de segurança.
0. **Sair:** Encerra a execução do programa.

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** Java (JDK 8 ou superior)
* **Biblioteca Padrão:**
  * `java.util.Scanner` (para leitura de dados do teclado)
  * `java.util.ArrayList` (para armazenamento dinâmico dos dados)

## 🔧 Como Executar o Projeto

Para rodar este projeto na sua máquina local, você precisará ter o Java JDK instalado.

1. **Clonar o repositório:**
   ```bash
   git clone [https://github.com/nilton-araripe-dev/arraylist-numbers-manager.git](https://github.com/nilton-araripe-dev/arraylist-numbers-manager.git)
2. **Navegar até a pasta do projeto:
   cd arraylist-numbers-manager
3. **Compilar o arquivo Java:
   javac ArrayLis.java
4. **Executar o programa:
   java ArrayLis
